# Hotel Booking

Le projet est séparé en deux parties :

- `src/`, `public/`, `vite.config.ts` : le **frontend** React/Vite.
- `backend/` : l'**API** Node.js, les comptes, les réservations et les données.

Lancez le frontend avec `npm run dev` et l'API dans un second terminal avec `npm run server`.
